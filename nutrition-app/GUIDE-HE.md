# נוטרי — מדריך הקמה מאפס

המדריך הזה מתחיל מהמחשב שלך ומסתיים באפליקציה חיה עם חשבונות, חברים ו-AI. אפשר לעצור אחרי כל חלק: כל חלק נותן משהו שעובד בפני עצמו.

**מה יש בסוף:**

| חלק | מה זה נותן | חובה? |
|---|---|---|
| 1. הרצה במחשב | לראות את האפליקציה ולבדוק שינויים | כן |
| 2. פרסום ב-Cloudflare | כתובת אמיתית באינטרנט, התקנה בטלפון | כן |
| 3. Supabase | התחברות עם Google, גיבוי, חברים והודעות | כן, לחברים |
| 4. מפתחות AI | עוזר, מצלמת קלוריות, אחוז שומן | לא, אפשר להתחיל בלי |
| 5. בדיקה שהכול עובד | רשימת סימון | כן |
| 6. עדכון גרסה | מה עושים כשמקבלים קבצים חדשים | כן |

## לפני שמתחילים: מה צריך

1. **Node.js** (גרסת LTS) מ-nodejs.org. בדיקה: פתח טרמינל והקלד `node -v`.
2. **חשבון Cloudflare** (חינם): dash.cloudflare.com
3. **חשבון Supabase** (חינם): supabase.com
4. **חשבון Google Cloud** (חינם): console.cloud.google.com. נחוץ רק בשביל כפתור "התחברות עם Google".
5. התיקייה `nutrition-app` מהארכיון (`nutrition-app.zip`). פרוס אותה לתיקייה קבועה, למשל `C:\nutri\nutrition-app`.

> **שים לב:** בקובץ `www/js/config.js` כבר רשום פרויקט Supabase (כתובת שמתחילה ב-`neswgxihjffyftzwxbjv`). אם הפרויקט הזה שלך, אפשר להמשיך איתו ולדלג על יצירת פרויקט בחלק 3. אם לא, צור פרויקט חדש והחלף את שני הערכים (חלק 3, שלב 6).

## חלק 1 — הרצה במחשב

```bash
cd nutrition-app
npm install
npm run dev
```

פתח בדפדפן `http://localhost:8787`. בלי שום הגדרה האפליקציה עובדת, חוץ מהתחברות, חברים והעוזר החכם.

להפסקה: `Ctrl+C` בטרמינל.

## חלק 2 — פרסום ב-Cloudflare

זה מעלה גם את האפליקציה וגם את השרת הקטן שלה (ה-Worker) לכתובת אחת, למשל `https://nutri.<שם-שלך>.workers.dev`.

### דרך קלה (Windows)

1. ודא ש-Node.js מותקן.
2. לחץ פעמיים על **`UPLOAD-APP.bat`** בתיקיית `nutrition-app`.
3. ייפתח חלון התחברות ל-Cloudflare. התחבר ואשר.
4. הסקריפט ישאל על מפתח AI (אפשר לדלג, ראה חלק 4) ויתן לך את הקישור, שגם נשמר בקובץ `APP-LINK.txt`.

להרצה חוזרת (עדכון): אותו קובץ.

### דרך ידנית (כל מערכת)

```bash
cd nutrition-app
npx wrangler login
npm run deploy
```

הפקודה האחרונה מדפיסה את הכתובת. בפעם הראשונה Wrangler יוצר לבד את מאגר ה-KV של התראות ה-Push.

### בדיקה

פתח `https://<הכתובת-שלך>/api/health`. אמור להופיע `{"ok":true,...}`.

### התקנה בטלפון

- **אנדרואיד (Chrome):** פתח את הכתובת, תפריט ⋮, "התקנה" / "הוספה למסך הבית".
- **אייפון (Safari):** כפתור שיתוף, "הוסף למסך הבית".

> **לפני שמשתפים קישורי הזמנה לחברים:** הכתובת היא חלק מכל קישור. מי שמשתמש בכתובת `workers.dev` ישאיר את הקישורים שלו תקפים רק כל עוד הכתובת קיימת. אם יש לך דומיין, חבר אותו עכשיו (Cloudflare, Workers & Pages, nutri, Settings, Domains & Routes) כדי לא לשבור קישורים בעתיד.

## חלק 3 — Supabase: התחברות, חברים והודעות

### 3.1 פרויקט חדש

1. supabase.com, **New project**. בחר שם, סיסמה לבסיס הנתונים (שמור אותה) ואזור קרוב (למשל Frankfurt).
2. המתן כדקה עד שהפרויקט מוכן.

### 3.2 הטבלאות (הכי חשוב)

1. בתפריט הצד: **SQL Editor, New query**.
2. פתח את הקובץ **`supabase/setup.sql`**, העתק את **כל** התוכן והדבק.
3. לחץ **Run**. אמור להופיע "Success".
4. אפשר להריץ שוב בכל זמן, כולל אחרי כל גרסה חדשה שמוסיפה טבלאות.
5. בדיקה: **Table Editor**. צריך לראות: `nutri_state`, `nutri_profiles`, `nutri_friend_requests`, `nutri_challenges`, `nutri_challenge_days`.

> **זו הסיבה לשגיאה "Couldn't reach the server" / "החברים עדיין לא הופעלו בשרת":** הטבלאות של החברים חסרות כי `setup.sql` הרצת לפני שהן נוספו. הרץ אותו שוב.

### 3.3 התחברות עם Google

1. ב-console.cloud.google.com צור פרויקט חדש.
2. **APIs & Services, OAuth consent screen:** User type External, מלא שם אפליקציה ואימייל, שמור.
3. **APIs & Services, Credentials, Create credentials, OAuth client ID:** סוג **Web application**.
4. תחת **Authorized redirect URIs** הוסף: `https://<מזהה-הפרויקט>.supabase.co/auth/v1/callback`
   (את הכתובת מוצאים ב-Supabase: Project Settings, API, "Project URL").
5. שמור, והעתק את **Client ID** ואת **Client secret**.
6. ב-Supabase: **Authentication, Sign In / Providers, Google**. הפעל, הדבק את שני הערכים ושמור.

### 3.4 כתובת האפליקציה ב-Supabase

**Authentication, URL Configuration:**
- **Site URL:** הכתובת של האפליקציה מחלק 2 (עם `/` בסוף).
- **Redirect URLs:** אותה כתובת.

### 3.5 חיבור האפליקציה לפרויקט

ב-Supabase: **Project Settings, API**:
- **Project URL**
- **Publishable key** (או anon key). הוא ציבורי בכוונה, ההגנה היא ב-RLS שב-`setup.sql`.

פתח `www/js/config.js` והחלף ב-`CLOUD`:

```js
export const CLOUD = {
  url: 'https://XXXX.supabase.co',
  anonKey: 'sb_publishable_XXXX',
};
```

### 3.6 פרסום מחדש

הרץ שוב את `UPLOAD-APP.bat` (או `npm run deploy`).

## חלק 4 — מפתחות AI (אופציונלי)

בלי מפתח, הכל עובד חוץ מהעוזר החכם, מצלמת הקלוריות ואחוז השומן מתמונה. כל מפתח הוא "ספק", ואפשר לשלב כמה. כל ספק ממלא מכסה חינמית קטנה.

| ספק | איפה מקבלים | מה הוא מזהה |
|---|---|---|
| Google (Gemini) | aistudio.google.com/apikey | טקסט ותמונות |
| Groq | console.groq.com/keys | טקסט ותמונות |
| Mistral | console.mistral.ai | טקסט ותמונות |
| Anthropic (Claude) | console.anthropic.com, API Keys | הכי מדויק, בתשלום |

### להוסיף מפתח

```bash
cd nutrition-app
npx wrangler secret put GOOGLE_API_KEY
```

הדבק את המפתח כשמתבקש. אותו דבר עם `GROQ_API_KEY`, `MISTRAL_API_KEY`, `ANTHROPIC_API_KEY`. אין צורך לפרסם מחדש.

> **שים לב לעלויות:** כל שימוש בעוזר ובמצלמה עולה כסף כשמגיעים לספק בתשלום (Anthropic). **עדיין אין מגבלת שימוש לכל משתמש.** לפני שמשתפים את האפליקציה עם הרבה אנשים, כדאי להגביל את הספקים החינמיים בלבד (`ENGINES_CHAT`, ראה `.env.example`) או לבנות מגבלות.

## חלק 5 — רשימת בדיקה: האם הכול עובד?

סמן ✓ אחרי שבדקת בטלפון ובמחשב:

- [ ] `https://<כתובת>/api/health` מחזיר `ok:true`.
- [ ] האפליקציה נפתחת, אפשר להירשם (הרשמה רגילה).
- [ ] **פרופיל, "גיבוי וחשבון", "התחברות עם Google"** מעביר ל-Google ומחזיר מחובר.
- [ ] ב-Supabase, ב-Table Editor, `nutri_state` מכילה שורה שלך.
- [ ] **פרופיל, חברים:** מוצג טופס "בחירת שם משתמש" (לא שגיאה). אחרי בחירת שם מופיעים הכפתורים "שליחה בוואטסאפ" ו-"העתקת קישור".
- [ ] פותחים את הקישור ממכשיר אחר, מתחברים, ומגיעים לפרופיל שלך.
- [ ] שולחים בקשה מחשבון אחד לשני, והבקשה מופיעה בפעמון (תיבת הודעות, "בקשות חברות").
- [ ] מפרופיל של חבר: "אתגר לתחרות", בחירת ימים והחמצות, שליחה. אצל החבר: הזמנה בתיבת ההודעות ("בקשות חברות"), אישור, ופס אתגר במסך הבית.
- [ ] (אם הגדרת AI) העוזר עונה, ומצלמת הקלוריות מזהה צלחת.

## חלק 6 — עדכון גרסה

כשמקבלים `nutrition-app.zip` חדש:

1. פרוס את הארכיון **מעל** התיקייה הקיימת (אל תמחק את `node_modules`; אם אין, `npm install`).
2. אם בפעם הראשונה אחרי גרסה 1.18: הרץ `npm install` (נוספה תלות לבדיקות בלבד).
3. **שמור את `www/js/config.js` שלך** אם שינית בו את `CLOUD`. הארכיון מחליף אותו.
4. אם בהודעה כתוב ש-`setup.sql` השתנה: הרץ אותו שוב ב-Supabase (חלק 3.2).
5. הרץ `UPLOAD-APP.bat` (או `npm run deploy`).
6. פתח את האפליקציה בטלפון. תופיע הודעה "גרסה חדשה זמינה, עדכון".

## פתרון בעיות

| תסמין | סיבה סבירה | מה לעשות |
|---|---|---|
| "Couldn't reach the server" בחברים | טבלאות חסרות, או אין חיבור | חלק 3.2, ואז "נסה שוב" |
| "החברים עדיין לא הופעלו בשרת" | הטבלאות חסרות | הרץ את `setup.sql` |
| התחברות עם Google מחזירה שגיאה | כתובת ההחזרה לא תואמת | בדוק חלקים 3.3 ו-3.4: כתובות זהות, כולל `https` |
| אחרי התחברות חוזרים להתחלה | Site URL שגוי ב-Supabase | חלק 3.4 |
| העוזר אומר "לא מוגדר" | אין מפתח AI | חלק 4 |
| השינויים לא מופיעים בטלפון | גרסה ישנה בזיכרון | סגור את האפליקציה ופתח, או לחץ "עדכון" כשמופיע |
| הפרויקט ב-Supabase "נעצר" | חבילה חינמית שלא היה בה שימוש זמן רב | ב-Supabase לחץ Restore project |
| בדיקת Chrome: שגיאת CSP | כתובת חיצונית חדשה | `www/_headers`: מותר רק `*.supabase.co` |

## מה עדיין לא קיים

- **סרטוני פרסומת** (הכנסות מפרסום).
- **חיבור לשעון / Apple Health / Health Connect:** לא אפשרי באפליקציית אינטרנט (PWA). צעדים ואימונים מוזנים ידנית.
- **ווידג'טים והתראות נייטיב, פרסום בחנויות:** דורש אפליקציה מקורית.
- **קואצ'ינג אנושי.**
- **תשלום ומנוי:** מסך התשלום קיים, החיבור לספק תשלום לא.
- **Sign in with Apple:** חובה לפני העלאה ל-App Store (כשיש התחברות עם Google).
- **מגבלות AI לכל משתמש.**
- **דיווח וחסימת משתמשים:** נדרש ב-App Store.
- **התראת Push על בקשת חברות.**

כל מה שכתוב כאן נבדק מול רכיבים מדומים. **לא נבדק מול Supabase, Cloudflare או ספקי AI אמיתיים.** אם צעד לא מתנהג כמו שכתוב, שלח לי את ההודעה המדויקת ואת החלק שבו אתה.
