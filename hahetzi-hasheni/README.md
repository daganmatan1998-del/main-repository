# החצי השני – אתר

האתר של "החצי השני | חצי בר חצי קפה", הלני המלכה 9, ירושלים.
אין שלב build. מעלים את התיקייה כמו שהיא לכל אחסון סטטי (Netlify, Cloudflare Pages, GitHub Pages).

| קובץ | מה יש בו |
| --- | --- |
| `index.html` | דף הבית: הפתיח, על המקום, למה חוזרים, מתי לבוא, קישורים לשאר הדפים, ושריון מקום |
| `menu.html` | תפריט הבר (אלכוהול ויין) ותפריט הקפה, עם תמונת התפריט המקורי |
| `reviews.html` | הביקורות מגוגל, עם סינון לפי נושא |
| `visit.html` | כתובת, שעות וכפתורי ניווט |
| `styles.css`, `site.js` | משותפים לכל הדפים. כל התוכן שחסר (שעות, תפריט קפה, תמונות, כתובת לטופס) נמצא בראש `site.js` |
| `privacy.html`, `terms.html`, `accessibility.html` | מדיניות פרטיות (כולל עוגיות), תנאי שימוש, הצהרת נגישות |
| `fonts.css`, `vendor/` | הגופנים וספריית האנימציה, מאוחסנים באתר עצמו כדי שאף דף לא יפנה לשרת חיצוני |
| `_headers` | כותרות אבטחה ל־Netlify ול־Cloudflare Pages |

ביקורות נוספות: מוסיפים רק ביקורות אמיתיות מגוגל, כ־`figure.rv-card` נוסף ב־`reviews.html`,
עם `data-tags` ו־`<mark data-t="...">` סביב המילים שמתאימות לסינון.

## מה מאומת ומה לא

האתר מציג רק דברים שמצאתי במקורות ציבוריים או בביקורות שנמסרו:

| פרט | מקור |
| --- | --- |
| השם והתיאור "חצי בר חצי קפה" | אינסטגרם `@ha.hetzi.ha.sheni` |
| הכתובת הלני המלכה 9, ירושלים | easy.co.il (דף 10159258) |
| מיקוד 9422105 | מאגר המיקודים לכתובת הזו |
| המוזיקה, הבירות, התנור בחוץ, השירות, המחירים, חמישי וראשון | ביקורות גוגל. בציטוטים תוקנו רק כתיב ופיסוק |

**חסר, וצריך להשלים מול המקום** (בראש `site.js`, בלוק `CONTENT TO SUPPLY`):

- `HOURS` – שעות פתיחה, 7 ערכים, מיום ראשון. כל עוד הרשימה ריקה, האתר מפנה לאינסטגרם.
- `MENU.cafe` – פריטי הקפה בצורה `{ name, desc, price }`. כל עוד הרשימה ריקה, מוצגת הודעה "התפריט בדרך לכאן".

**תפריט הבר** (אלכוהול ויין) כתוב ישירות ב־`menu.html`, בטבלאות, ומועתק מ־`menu-alcohol.jpg`, שמוצג גם כתמונה ("התפריט המקורי").
אותם מחירים מופיעים גם בנתוני ה־JSON-LD (`hasMenu`) בראש `index.html` ו־`menu.html`. מחיר שמשתנה צריך להתעדכן בטבלה וגם בשני בלוקי ה־JSON-LD.
תוקנו רק שגיאות כתיב ברורות: צ'ייסר, קאסמיגוס, בכרובקה, יגרמייסטר, שנן בלאן, צ'ינזנו.
השמות אלמנוס, פיקוריטו, דאקור, טובי נייט ופידג' נשארו כמו בתפריט, כי לא הצלחתי לאמת את האיות שלהם.
- `PHOTOS` – תמונות אמיתיות מהמקום `{ src, srcMobile, alt }`. אזור הגלריה מופיע רק כשיש תמונות.
  כדאי לחתוך `src` ל־16:10 או 4:5, ואת `srcMobile` ל־4:5.
- `CONFIG.reservationEndpoint` – כתובת שמקבלת POST של JSON עם `date, time, guests, name, phone, email, notes`
  (למשל Formspree או Cloudflare Worker). כל עוד היא ריקה, הטופס מכין את הבקשה כטקסט להעתקה ושליחה בהודעה באינסטגרם,
  ואומר במפורש שהבקשה עוד לא נשלחה. אין אישור הזמנה מזויף.
- טלפון – לא נמצא מספר מאומת, אז אין מספר באתר.
- `og.jpg` – תמונת השיתוף נוצרה מה־hero. אפשר להחליף בצילום אמיתי בגודל 1200×630.

## תנועה

GSAP 3.12.5 ו־ScrollTrigger מ־cdnjs. בלי הספריות (או עם `prefers-reduced-motion`) כל התוכן גלוי ופעיל, רק בלי האנימציות.
הדף בנוי מימין לשמאל, והקטע האופקי ("למה חוזרים") נע ימינה. `containerAnimation` של ScrollTrigger מניח תנועה שמאלה,
ולכן החשיפה של הלוחות שם נעשית עם IntersectionObserver.

## משפטי ופרטיות

**לפני העלייה לאוויר צריך למלא את `LEGAL` בראש `site.js`**: שם העסק, ח.פ./ע.מ., אימייל, טלפון, רכז נגישות ופרטי קשר,
תיאור הנגישות הפיזית של המקום, וכמה ימים שומרים פרטי הזמנה. כל שדה ריק מופיע בדפים המשפטיים כ־"[להשלמה: ...]".
כדאי להשתמש בפרטי קשר של העסק (אימייל עסקי, קו של העסק) ולא בפרטים אישיים של הבעלים.
את הטקסטים המשפטיים כדאי להעביר לעיון של עורך דין לפני העלייה לאוויר.

האזהרה "שתייה מופרזת של משקאות משכרים מסכנת חיים ומזיקה לבריאות" ואיסור המכירה לקטינים מופיעים בתחתית כל דף ובדף התפריט.

## שכבות ההגנה

- **אין צד שלישי.** גופנים, GSAP ותמונות נטענים מהאתר עצמו. אין אנליטיקה, אין עוגיות, אין פיקסלים.
- **Content-Security-Policy** בכל דף (תגית meta) וב־`_headers`: קוד רץ ומידע נשלח רק מהאתר עצמו.
  כשמגדירים `reservationEndpoint`, מוסיפים את הכתובת שלו ל־`connect-src` בשני המקומות.
- **כותרות אבטחה** ב־`_headers`: HSTS, nosniff, מניעת הטמעה במסגרת (clickjacking), Referrer-Policy, Permissions-Policy.
- **הטופס:** מגבלת אורך לכל שדה, שדה מלכודת לבוטים ובדיקת זמן מילוי, שליחה רק ל־https בלי עוגיות ובלי referrer,
  שום דבר לא נשמר בדפדפן, וכפתור "מחיקת הפרטים".
- **קישורים חיצוניים** עם `noopener noreferrer`.
