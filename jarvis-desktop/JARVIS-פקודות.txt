-----------------------------------------------------
  1. לפנות אליו
-----------------------------------------------------

  היי ג'רוויס ...          hey jarvis ...
  ג'רוויס ...              jarvis ...
  שומע ג'רוויס             jarvis are you there
  אתה שם ג'רוויס           ok jarvis ...
  ... ג'רוויס              ... jarvis

איך זה עובד:
  השם צריך להיות בהתחלה, או בסוף משפט קצר.
  משפט עד 6 מילים עובר גם בלי שם בכלל.
  משפט ארוך שלא מתחיל בשמו - מתעלם.

שמות שהוא מזהה גם כשהתמלול משבש:
  jarvis  jervis  javis  jarviss  jarvus  jarv
  ג'רוויס  גרוויס  ג'ארוויס  ג'רויס

מילים שהוא מתעלם מהן סביב השם:
  היי  הי  שלום  אוקיי  נו  תשמע  שומע  אתה  שם  תקשיב
  hey  hi  hello  ok  okay  yo  listen  look  are  you  there

אחרי שהוא ענה: 30 שניות בלי צורך בשם.

בלי לדבר:
  לחיצה בודדת על הכדור  =  מתחיל מיד, וגם קוטע אותו


-----------------------------------------------------
  2. שינה
-----------------------------------------------------

  ג'רוויס לך לישון         jarvis go down
  תלך לישון                go to sleep
  כבה את עצמך              shut down | power down
  תיכבה                    stand down | go offline
  כיבוי                    sleep mode

  עד 6 מילים. "the server had to shut down" לא מפיל אותו.

להעיר:
  תתעורר                   wake up | get up
  תקום | קום               come back | power up
  חזור | תחזור             are you there | are you awake
  התעורר                   boot up | start up

  או Ctrl+Shift+Space

מה קורה בשינה:
  נעלם מהמסך, לא עונה לכלום.
  המיקרופון נשאר פתוח רק כדי לשמוע מילת הערה.
  שולח לתמלול רק כשמזוהה קול - חדר שקט לא עולה כלום.


-----------------------------------------------------
  3. השתקה מלאה
-----------------------------------------------------

  קליק ימני על הכדור -> Stop listening

  שונה משינה: הערוץ נסגר לגמרי, נורית המיקרופון
  בווינדוס נכבית, ואף מילה לא מחזירה אותו.
  נשמר גם אחרי הפעלה מחדש.

  להחזיר: קליק ימני -> Resume listening


-----------------------------------------------------
  4. שפה
-----------------------------------------------------

לאנגלית (כתום):
  מצב אנגלית               english mode
  תעבור למצב אנגלית        go to english | switch to english
  תדבר אנגלית              speak english
  מצב אולטרון              ultron mode
  תהפוך לאולטרון           become ultron
  תהיה אולטרון             switch to ultron | go to ultron
  תעבור לאולטרון           i need ultron | give me ultron
  אני צריך את אולטרון      wake ultron

לעברית (תכלת):
  מצב עברית                hebrew mode
  תעבור למצב עברית         go to hebrew | switch to hebrew
  תדבר עברית               speak hebrew
  מצב ג'רוויס              jarvis mode
  תהפוך לג'רוויס           become jarvis
  תהיה ג'רוויס             back to jarvis
  תחזור לג'רוויס           switch to jarvis

חשוב:
  כל ניסוח דורש פועל. "jarvis" לבדו הוא פנייה
  ולא מחליף מצב.
  עד 6 מילים.

הצבע הוא הסימן: תכלת = עברית, כתום = אנגלית.


-----------------------------------------------------
  5. פתיחת אתרים

  תפתח את עליאקספרס        open aliexpress
  קח אותי לשופיפיי         take me to shopify admin
  תיכנס ל...               go to ... | pull up ...

אתרים שהוא מכיר בשמם:

  shopify  cloudflare  gmail  facebook  instagram
  tiktok  x  reddit  github  chatgpt  wikipedia  whatsapp

-----------------------------------------------------
  7. סגירת חלונות
-----------------------------------------------------

  סגור את החלון הזה        close this window
                           close this

  סגור את כרום             close chrome
  סגור את החלון של ...     close the ... window

  סגור את הטאב             close this tab
  סגור את הטאב של ...      close the ... tab

ההבדל:
  close this window    - החלון שבפוקוס עכשיו
  close ... window     - מחפש לפי טקסט בכותרת
  close ... tab        - טאב בודד, החלון נשאר פתוח

טיפ: כותרת חלון כרום היא שם הדף הפעיל, אז
     "close youtube" יתפוס טוב יותר מ-"close chrome".

תמיד שולח בקשת סגירה רגילה - עבודה לא שמורה
עדיין תשאל אותך. לעולם לא סוגר את עצמו.

-----------------------------------------------------
  אפליקציית הבסיס, סגירת תוכנות, ואגרופים
-----------------------------------------------------

  לפתוח את אפליקציית הבסיס (האתר ב-Chrome, בחלון משלו):
  תפתח את אפליקציית הבסיס      open your base app
  תפתח את האפליקציה שלך        open the jarvis app | open your app

  לסגור תוכנה שלמה, כל החלונות שלה:
  תסגור את אפליקציית ...        close the ... app
  תסגור את האפליקציה של ...    close the ... application | program
  תסגור את סביבת העבודה        close the workspace
  תסגור את אפליקציית הכרום     close the chrome app   (כל הכרום)
  תסגור את אפליקציית הבסיס     close your base app

  בלי המילה "אפליקציה" ("תסגור את ספוטיפיי") הוא מחפש
  קודם טאב בשם הזה, ורק אם אין - סוגר את התוכנה.

  לפתוח תוכנה מותקנת במחשב (לא את האתר שלה):
  תפתח את אפליקציית ...        open ... app
  תפתח את התוכנה ...           open the ... application | program
  למשל: open discord app | open spotify app | open steam app
        open vs code app | open file explorer app | open chrome app
  בלי המילה "app" ("open chrome") - כמו תמיד.
  אם התוכנה לא מותקנת - הוא אומר את זה, ולא פותח את האתר במקומה.

  go full screen  (מהכדור במחשב):
     פותח את אפליקציית ג'רוויס שעל שולחן העבודה (האתר ב-Chrome), מוגדלת.
     הכדור נעלם מהמסך ומפסיק להקשיב, המצלמה יורדת לשורת המשימות.
     נשארים רק המודלים התלת-מימדיים וחלונית השירים.
     להחזיר את הכדור: Ctrl+Shift+Space.

  לפתוח את התיקייה "ג'רוויס קבצים" שעל שולחן העבודה:
  open the jarvis folder | open my jarvis files
  תפתח את התיקייה של ג'רוויס | תפתח את ג'רוויס קבצים

  קובץ תלת-מימד באתר:
  גוררים קובץ .glb / .gltf / .obj / .stl מהתיקייה ומשחררים על האתר,
  או בוחרים אותו בכפתור הקבצים. נפתח חלון גדול:
  גרירה מסובבת, גלגלת מקרבת, גרירה ימנית מזיזה, Esc סוגר.

  אגרוף אחד = להחזיק את הכפתור השמאלי של העכבר:
  יד פתוחה (או אצבע מצביעה) מורמת, ואז אגרוף - הכפתור לחוץ.
  מזיזים את האגרוף - גוררים (קובץ, בחירה של כמה קבצים, חלון).
  פותחים את היד - הכפתור משתחרר.
  אגרוף שלא היה קודם יד פתוחה, או יד שמונחת למטה - לא עושה כלום.
  יד שיצאה מהמצלמה, או מצלמה שנסגרה - הכפתור משתחרר לבד.

  צבעים בחלון המצלמה:
     כתום-אדום = אגרוף שמחזיק את הכפתור (עיגול מלא בכף היד = לחוץ)
     סגול      = שני אגרופים לפני מזעור (קו מלא ועיגול = מוזער)
  אפשר לסובב את האגרוף לכל כיוון בזמן הגרירה - הוא משחרר רק כשהיד נפתחת.

  באתר:
  כפתור המיקרופון העגול (וגם MIC) - צליל קטן, והוא מקשיב. אדום כשהוא מקשיב.
  הכדור של ג'רוויס: גרירה מסובבת, גלגלת מקרבת ומרחיקה, תמיד באמצע המסך.
  אחרי 8 שניות בלי לגעת - חוזר לסיבוב האיטי.

  למזער (כמו הקו ליד ה-X):
  שני אגרופים מורמים, רחוקים זה מזה, ואז מקרבים
  עד שהם נוגעים - החלון שאתה עובד בו יורד לשורת המשימות.
  עובד כשחלון המצלמה פתוח.
