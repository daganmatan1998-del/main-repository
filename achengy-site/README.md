# ACHENGY landing page

Static site, no build step. English, left-to-right. Deploys as-is on Cloudflare Pages or Netlify (`_headers` carries the CSP).

Concept: **lit from within**. A black dial whose cyan hands are the only light on the page. The hero pushes the camera into the dial on scroll, the cursor is a lume dot with a minute ring, the loader is a sweeping second hand, and page changes wipe across like one.

Files: `index.html`, `privacy.html`, `terms.html`, `accessibility.html`, `styles.css`, `site.js` (CONFIG block at top), `boot.js`, `fonts.css` (embedded Anton / Rubik / Caveat), `vendor/` (GSAP 3.12.5 + ScrollTrigger), `img/`.
